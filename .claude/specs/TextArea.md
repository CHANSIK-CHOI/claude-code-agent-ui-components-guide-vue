### 0. Atomic 계층 & 파일 배치

- **계층**: atoms — `<textarea>` 단일 엘리먼트 기반, 외부 컴포넌트 의존 없이 장문 텍스트 입력 역할을 수행하는 최소 단위
- **배치 경로**: `components/atoms/TextArea.vue`
- **Base/Wrapper 분리**: Base만 구성. 특수 Wrapper 변형(검색, 비밀번호 토글 등)이 없으므로 분리하지 않는다.

계층 판단 근거: Input과 동급의 폼 입력 atom. `<textarea>` 특성(높이, 리사이즈, 카운터)이 추가될 뿐 다른 컴포넌트를 조합하지 않는다.

---

### 1. 컴포넌트 개요

사용자가 여러 줄의 텍스트를 입력하는 폼 요소로, 최대 글자 수 카운터를 내장합니다.
상품 문의, 리뷰 작성, 메모 입력 등 긴 텍스트가 필요한 폼 화면에서 사용합니다.
라벨이나 도움말 텍스트가 필요한 경우 `FormField`와 조합해 사용합니다.

---

### 2. 영역 구성 (Area Map)

- ① **입력 필드(Field)** — `<textarea>` 요소. 사용자가 텍스트를 직접 입력하는 영역. placeholder 텍스트 표시 / 필수
- ② **카운터(Counter)** — 필드 하단 우측에 `현재 글자 수 / 최대 글자 수` 형태로 표시. 최대 글자 수(maxLength)가 설정된 경우에만 노출 / 조건부
- ③ **스크롤바 인디케이터** — 내용이 필드 높이를 초과할 때 나타나는 커스텀 스크롤바 / 조건부

카운터는 필드 내부 패딩 영역 하단 우측에 위치하여, 입력 텍스트와 같은 컨테이너 안에 배치된다.

---

### 2-1. Props 목록

| 항목 | 설명 | 기본값 |
|------|------|--------|
| 입력값 | 텍스트 영역에 표시되는 현재 값 (v-model 연동) | 빈 값 |
| 최대 글자 수 | 입력 가능한 최대 글자 수. 설정하면 카운터 영역 노출. 미설정 시 카운터 숨김 | 미설정 |
| Placeholder | 값이 없을 때 필드 내에 표시할 안내 텍스트 | 빈 값 |
| 행 수(rows) | 텍스트 영역의 초기 세로 높이 기준. 브라우저 기본 `rows` 속성에 대응 | 미설정 (CSS 높이로 제어) |
| 리사이즈 방향 | 사용자가 필드 크기를 조절할 수 있는 방향. none / vertical / horizontal / both | none |
| 에러 여부 | 켜면 에러 상태로 표시 (`aria-invalid="true"` 자동 적용). 에러 메시지 텍스트는 FormField 담당 | 끔 |
| 비활성 여부 | 켜면 입력 불가, 시각적으로 흐려짐 | 끔 |
| 읽기 전용 여부 | 켜면 입력만 차단. 포커스·선택·복사는 가능 | 끔 |
| id | 외부 `<label>`과 연결하는 고유 식별자. 미전달 시 내부 자동 생성 | 미설정 (자동 생성) |

> `aria-describedby`, `aria-label`, `autocomplete` 등 네이티브 속성은 `v-bind="$attrs"` 위임으로 직접 전달 가능.

### 3. Variant 목록

TextArea 컴포넌트는 별도의 시각적 variant가 없으며, 상태(State)에 따라 외관이 변합니다.

---

### 4. 상태(State) 정의

| 상태 | 시각적 변화 | 기능적 변화 |
|------|-----------|-----------|
| default | 기본 테두리(연한 회색), 흰 배경, placeholder 텍스트 표시 | 입력 가능 |
| filled | 기본 테두리(연한 회색), 흰 배경, 입력된 텍스트가 중간 회색으로 표시 | 입력 가능 |
| focus | 테두리 색상 어둡게(Input과 동일), 흰 배경 유지 | 키보드 입력 활성 |
| disabled | 배경 어둡게(회색 계열), 테두리 유지, 텍스트 흐리게, 커서 변경 | 입력 차단, 클릭 차단, 포커스 차단 |
| readonly | default와 시각적으로 동일 | 입력만 차단. 포커스·선택·복사는 가능 |
| error | 테두리 색상 에러 색상으로 변경. 카운터 색상도 에러 색상 적용 | 입력은 가능 |
| maxLength 초과 | 카운터 텍스트 에러 색상으로 강조 | 입력 추가 차단 (`maxlength` 속성으로 네이티브 제한) |

---

### 5. 동작 규칙

- disabled 상태에서는 입력 이벤트, 포커스, 클릭 모두 차단
- readonly 상태에서는 입력만 차단. 포커스, 텍스트 선택, 복사는 가능
- placeholder는 입력값이 없을 때만 표시
- 최대 글자 수(maxLength)가 설정되면 카운터가 노출되고, `maxlength` 네이티브 속성으로 브라우저 수준에서도 입력을 차단
- 카운터는 `현재 글자 수 / 최대 글자 수` 형태로 실시간 갱신됨
- 최대 글자 수가 미설정이면 카운터 영역 자체가 렌더링되지 않음
- 리사이즈 방향이 `none`(기본값)이면 사용자가 직접 크기를 조절할 수 없음
- 필드 너비는 부모 컨테이너 너비를 따름 (고정 너비 없음)
- 내용이 필드 높이를 초과하면 내부 스크롤이 활성화됨
- 외부에서 id prop이 전달되면 내부 자동 생성 id 대신 외부 id를 사용
- 라벨/도움말/툴팁 관련 동작은 `FormField` 명세를 참조

### 6. 이벤트 목록

| 이벤트 | 발생 시점 | 전달 정보 |
|--------|---------|---------|
| update:modelValue | 입력값이 변경될 때 (입력 시마다) | 현재 입력값(문자열) |
| focus | 텍스트 영역에 포커스가 잡힐 때 | — |
| blur | 텍스트 영역에서 포커스가 벗어날 때 | 현재 입력값(문자열) |
| change | 입력 완료 후 포커스 이탈 시 (값이 변경된 경우) | 현재 입력값(문자열) |

### 7. 접근성 요구사항

| 항목 | 조건 | 요구사항 |
|------|------|---------|
| 라벨 연결 | FormField와 조합 시 | `<label for>` ↔ `<textarea id>` 연결. inputId가 일치해야 함 |
| 라벨 미사용 시 | 단독 사용 시 | `aria-label` 또는 `aria-labelledby`를 `$attrs`로 전달 필요 |
| 에러 메시지 연결 | error 상태일 때 | `aria-describedby`를 `$attrs`로 직접 전달하여 에러 메시지 요소 연결 |
| 카운터 연결 | maxLength 설정 시 | 카운터 요소에 고유 id 부여 후 `aria-describedby`로 `<textarea>`와 연결 |
| 유효성 상태 전달 | error 상태일 때 | `error="true"` → `<textarea aria-invalid="true">` 자동 적용 |
| 비활성 알림 | disabled 상태일 때 | 네이티브 `<textarea disabled>` 속성으로 보조기기에 자동 전달 |
| 읽기 전용 알림 | readonly 상태일 때 | 네이티브 `<textarea readonly>` 속성으로 보조기기에 자동 전달 |
| 포커스 표시 | 키보드 포커스 시 | 외곽선(포커스 링) 시각적으로 반드시 표시 |
| 키보드 접근 | 항상 | Tab 키로 포커스 이동. 필드 내 방향키·Enter·기타 키보드 입력 기본 동작 지원 |
| 카운터 텍스트 | 항상 | 스크린리더가 읽을 수 있는 텍스트로 렌더링 (이미지나 icon 금지) |
