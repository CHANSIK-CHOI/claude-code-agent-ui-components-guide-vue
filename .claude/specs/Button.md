# Button 컴포넌트 명세

## 0. Atomic 계층 & 파일 배치

- **계층**: atoms — 외부 컴포넌트 의존 없음, 단일 역할
- **배치 경로**: `components/atoms/Button.vue`
- **카테고리 barrel**: `components/atoms/index.ts`
- **Base/Wrapper 분리**: Base만 (`Button.vue`)

---

## 1. 컴포넌트 개요

사용자의 주요/보조 액션을 유도하는 클릭 가능한 인터랙티브 요소. 폼 제출, CTA(결제/다음), 팝업 확인/취소, 탐색(전체보기), 이벤트 프로모션 진입 등 화면 내 모든 액션 진입점에 사용된다.
링크 이동이 필요한 경우 `LinkButton` 컴포넌트를, 아이콘 단독 버튼이 필요한 경우 `IconButton` 컴포넌트를 사용한다.

---

## 2. 영역 구성 (Area Map)

- ① **루트(Root)** — 전체 클릭 영역을 감싸는 컨테이너 / 필수
- ② **리딩 아이콘(Leading Icon)** — 라벨 앞에 노출되는 아이콘 슬롯 / 선택
- ③ **라벨(Label)** — 버튼 텍스트 / 필수
- ④ **트레일링 아이콘(Trailing Icon)** — 라벨 뒤에 노출되는 아이콘 슬롯 / 선택 (예: "나만의 드시모네 ⌄", "전체보기 >")

---

## 2-1. Props 목록

| 항목        | 설명                              | 기본값  |
| ----------- | --------------------------------- | ------- |
| 형태 선택   | solid / line / text               | solid   |
| 컬러 선택   | primary / secondary / black       | primary |
| 크기 선택   | sm / md / lg                      | md      |
| 라운드 여부 | 켜면 pill(완전히 둥근) 형태       | 끔      |
| 비활성 여부 | 켜면 클릭 불가, 시각적으로 흐려짐 | 끔      |
| 버튼 타입   | button / submit                   | button  |

---

## 3. Variant 목록

### 3-1. shape (형태 축)

| shape | 사용 맥락                                                |
| ----- | -------------------------------------------------------- |
| solid | 기본 형태. 배경색 채움. 주요/보조 CTA                    |
| line  | 아웃라인 형태. 배경 투명, 테두리만. 보조 액션            |
| text  | 배경·테두리 없음. 인라인 보조 액션 (예: 팝업 "건너뛰기") |

### 3-2. color (컬러 축)

| color     | 사용 맥락                                          |
| --------- | -------------------------------------------------- |
| primary   | 주요 CTA, 긍정 확정 액션 (결제하기, 다음, 확인)    |
| secondary | 보조 액션, 취소/뒤로가기 계열                      |
| black     | 강조 톤이 필요한 단일 액션 (프로모션 단독 배치 등) |

### 3-3. size (크기 축)

| size | 사용 맥락                               |
| ---- | --------------------------------------- |
| lg   | 화면 하단 고정 메인 CTA (Bottom Button) |
| md   | 팝업/모달 내부 버튼, 인라인 액션        |
| sm   | 좁은 공간의 보조 버튼, 필터/정렬 트리거 |

### 3-4. round (모서리 둥글기 축)

| round        | 사용 맥락                                        |
| ------------ | ------------------------------------------------ |
| 끔 (default) | 기본 모서리 — 일반 버튼                          |
| 켬 (full)    | 완전히 둥근 pill 형태 — Round Button, 플로팅 CTA |

---

## 4. 상태(State) 정의

| 상태             | 시각적 변화                            | 기능적 변화   |
| ---------------- | -------------------------------------- | ------------- |
| default          | 기본 스타일                            | —             |
| hover            | 배경/테두리 어둡게                     | —             |
| focus            | 포커스 링 표시                         | 키보드 포커스 |
| active (pressed) | 배경 더 어둡게                         | —             |
| disabled         | 배경 회색으로 바뀌고 흐려짐, 커서 변경 | 클릭 차단     |

---

## 5. 동작 규칙

### 5-1. 공통 규칙

- `disabled` 상태에서는 클릭 이벤트가 발생하지 않는다
- 버튼의 너비는 기본적으로 콘텐츠 크기에 맞춘다. 전체 너비 레이아웃은 부모가 결정한다
- 라벨(기본 슬롯)은 항상 필수다. 아이콘 단독 버튼은 `IconButton` 컴포넌트를 사용한다
- 비동기 액션 중 클릭 차단이 필요한 경우 부모 컴포넌트가 `:disabled="isLoading"` prop으로 제어한다. Button은 `loading` 상태를 별도 구현하지 않는다

### 5-2. 상호배타 조합 (Mutual Exclusion)

| #   | 조건                      | 처리 규칙                                                                                          |
| --- | ------------------------- | -------------------------------------------------------------------------------------------------- |
| ①   | `shape=text` + `color`    | text는 배경·테두리가 없어 color 축이 시각적으로 의미를 갖지 않음 → 텍스트 색으로만 반영하거나 무시 |
| ②   | `shape=text` + `round=켬` | text는 모서리 둥글기 개념이 적용되지 않음 → round 무시                                             |

### 5-3. 상태 우선순위

- `disabled` > `active` > `hover` > `default`

---

## 6. 이벤트 목록

| 이벤트 | 발생 시점                    | 전달 정보        |
| ------ | ---------------------------- | ---------------- |
| click  | 클릭/탭 시 (`disabled` 제외) | 클릭 이벤트 객체 |

키보드 Enter·Space 입력 시에도 `<button>` 기본 동작에 의해 click 이벤트가 발생한다.

---

## 7. 접근성 요구사항

| 항목        | 조건             | 요구사항                                                     |
| ----------- | ---------------- | ------------------------------------------------------------ |
| 시맨틱 태그 | 항상             | `<button type="button">` 또는 `<button type="submit">` 사용  |
| 버튼 타입   | 항상             | `type="button"` 또는 `type="submit"` 필수                    |
| 키보드 접근 | 항상             | Enter·Space로 클릭 발생                                      |
| 비활성 알림 | disabled         | 네이티브 `<button>`의 `disabled` 속성으로 보조기기에 자동 전달 (aria-disabled 중복 금지) |
| 포커스 표시 | 키보드 포커스 시 | `:focus-visible` 외곽선 표시, `outline: none` 단독 사용 금지 |
| 색상 대비   | 모든 variant     | 라벨 텍스트와 배경 대비 4.5:1 이상 (WCAG AA)                 |
| 상태 표현   | disabled         | 색상만으로 비활성 표현 금지 → opacity·cursor 병행            |

Button은 헤드리스 라이브러리 없이 직접 구현 가능한 기본 atom.
