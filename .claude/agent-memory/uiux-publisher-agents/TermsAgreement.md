# TermsAgreement — 구현 메모

- **파일 경로**: components/molecules/TermsAgreement.vue
- **계층**: molecules
- **구현 완료일**: 2026-05-28
- **비표준 구현**:
  - `hasAccordionItems` computed(`items.some(item => item.type === 'accordion')`)로 컨테이너 분기:
    - `<component :is="hasAccordionItems ? Accordion : 'div'">` 단일 컨테이너 패턴으로 통합 (WARN-1 수정)
    - `accordion` 타입은 `<AccordionItem>`, `checkbox/popup` 타입은 `<div class="termsAgreement__item">` — v-for 내부 단일 출처
    - Accordion 전용 props/이벤트는 `accordionProps` computed(`{ type: 'multiple', 'onUpdate:modelValue': onAccordionChange }`)로 묶어 `v-bind="accordionProps"` 일괄 전달. `'onUpdate:modelValue'` 키는 Vue가 이벤트 리스너로 등록 (template의 `@update:model-value`와 동일)
  - Accordion import: `import Accordion, { AccordionItem, AccordionTrigger, AccordionContent } from './Accordion.vue'` — default export + named export 한 줄 혼합 import (QA 지적된 `import { Accordion }` named import 방식은 오류 → default import 방식이 올바름)
  - AccordionTrigger에 `headTrigger: true` 사용 — 체크박스와 분리된 별도 트리거 패턴
  - accordion 아이콘 회전은 `:deep(.accordion__trigger--head[data-state='open'])` 선택자로 처리 (Accordion.vue의 plain object 컴포넌트 scoped 미전달 한계)
  - SVG 아이콘은 `?skipsvgo` 패턴 (smallChevronRight, smallChevronDown)
  - `items` watch(immediate:true): 초기화 시 신규 항목은 `checkedMap.value[item.value] ?? props.allChecked`로 allChecked 초기값 반영. emit 없음 — 마운트 초기화 전담. `isHandlingChange` guard 미적용 — 책임이 다르므로 주석으로 명시 (항목 구조 변경에 따른 checkedMap 재구성은 allChecked 인터랙션 흐름과 무관, 항상 재구성해야 함)
  - `allChecked` watch: false 외부 주입 시 checkedMap 변경 안 함 (개별 상태 유지, WARN-2 계약). guard 플래그 `isHandlingChange`로 handler 흐름에서 온 prop 변경 무시 (WARN-3 수정)
  - `isHandlingChange` guard 플래그 (let boolean): `onAllCheckedChange` 실행 시 true → emit → 부모 prop 업데이트 → watch 재진입 차단. `nextTick` 후 false 복원. React의 `useRef(false)` 중복 업데이트 방지 패턴과 동일
  - `onAllCheckedChange` 핸들러: isHandlingChange=true → checkedMap 갱신 → `update:checked` (항목별) → `update:allChecked` emit → nextTick 후 isHandlingChange=false
  - `prevOpenValues: string[]` — 단일 let 배열로 Accordion의 이전 열림 상태 추적. `onAccordionChange(nextOpenValues)` 에서 prev 대비 새로 추가된 value에만 `accordion-open` emit. accordion 타입 없을 때는 Accordion 미마운트로 자연스럽게 비활성화됨
  - `onAccordionChange` 인자 타입: Accordion의 `@update:model-value` 이벤트는 `string | string[]` 유니언 → 내부에서 `Array.isArray()`로 정규화
- **개발자 핸드오프**:
  - `items` prop — API 연동 필요 (약관 항목 배열)
  - `@update:checked` emit — 개별 체크 상태 변경 시 수신
  - `@popup-click` emit — popup 타입 항목 클릭 시 팝업 열기 처리
  - `@accordion-open` emit — accordion 타입 항목이 펼쳐질 때 수신 (열릴 때만, value 전달)
