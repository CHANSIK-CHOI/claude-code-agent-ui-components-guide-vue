# /sync-docs — CLAUDE.md + ONBOARDING.md 동기화

`.claude/rules/`, `.claude/agents/`, `.claude/commands/` 파일 변경 사항을
CLAUDE.md와 ONBOARDING.md에 반영한다.

> 본 명령은 에이전트를 호출하지 않고 Claude 가 직접 파일을 읽고 차이를 분석한 뒤 두 문서를 갱신한다.

**1단계 승인 후 Shift+Tab으로 accept mode 전환 필요.**

---

## 1단계 (plan mode): 현재 상태 수집 및 차이 분석

다음 파일을 모두 읽는다:

- `.claude/rules/` 디렉토리의 파일 목록 + 각 파일 첫 줄(제목 확인)
- `.claude/agents/` 디렉토리의 파일 목록 + 각 파일 첫 줄
- `.claude/commands/` 디렉토리의 파일 목록
- `.claude/CLAUDE.md` 전체 내용
- `ONBOARDING.md` 전체 내용

분석 후 다음을 보고한다:

1. **CLAUDE.md Rules 참조 섹션** — 실제 파일 목록과 불일치 항목 (추가/삭제)
2. **ONBOARDING.md** — 반영되어야 할 변경 사항 요약 (어떤 섹션이 바뀌어야 하는지)
3. 변경이 없으면 "이미 최신 상태입니다." 보고 후 종료

## 2단계 (accept mode): CLAUDE.md Rules 참조 섹션 동기화

1단계에서 불일치가 발견된 경우에만 실행.

- 파일이 추가됐으면 → 섹션에 항목 추가 (파일명 + 파일 내 h1 기반 한 줄 설명)
- 파일이 삭제됐으면 → 섹션에서 항목 제거
- 기존 순서 유지, 새 파일은 맨 아래 추가

## 3단계 (accept mode): ONBOARDING.md 전체 재생성

현재 ONBOARDING.md의 9개 섹션 구조를 유지하면서 변경 사항을 반영해 재생성한다.

재생성 원칙:
- 기존 섹션 구조 그대로 유지 (전체 구조 한눈에 보기 / 권한 설정 / 훅 설정 / 슬래시 명령 / 에이전트 카탈로그 / MCP 서버 / 검수 흐름 / 자주 쓰는 시나리오 / 주의사항)
- 새 rules 파일 → 해당 내용이 언급되는 섹션에 추가
- 새 에이전트 → 에이전트 카탈로그 테이블과 워크플로우 섹션에 추가
- 새 commands → 슬래시 명령 섹션에 사용 예시 포함해 추가
- 삭제된 항목 → 모든 섹션에서 제거
- 변경되지 않은 내용은 그대로 유지 (불필요한 재작성 없음)

## 4단계: 완료 보고

- CLAUDE.md에서 추가/제거된 항목
- ONBOARDING.md에서 변경된 섹션

> ONBOARDING.md 는 프로젝트 구조·워크플로우를 설명하는 로컬 문서로만 유지한다 (외부 공유 업로드 없음). 파일이 없으면 3단계에서 신규 생성한다.
